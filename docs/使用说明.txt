二、视频
输入：MP4、MOV、MKV、AVI、WebM、WMV、FLV、M4V、TS、MTS、M2TS、MPEG、MPG、3GP、OGV。
输出：MP4、MOV、MKV、WebM、AVI、TS、MPEG、WMV、FLV。
编码：H.264、H.265、AV1、VP9、VP8、MPEG-4、MPEG-2、MPEG-1、WMV2、FLV1，
具体选项按容器兼容性提供。旧格式通常兼容面较窄或压缩率较低。
“质量优先”：数值越小画质越好，不保证文件体积。
“指定平均码率”：可填写 kbps / Mbps；平均码率不等于恒定码率，最终大小仅为估计。
“目标文件体积”：填写每个文件的 MB / KB 上限，扣除音频与封装预算后计算码率。
CPU 支持的编码使用两遍编码，并检查结果，最多三轮；无法达标时失败并显示原因。
目标体积模式请使用有损音频编码或移除音频，不能复制未知体积音轨或使用 PCM。
硬件编码选项仅在短片实际编码探测成功后出现；失败时可选择 CPU 重试。
宽高 0 表示保持源尺寸 / 自动推导；支持保持比例与常用分辨率按钮。
直接封装转换不重编码，不能同时改变码率、体积、画面或音频。
处理主视频及首条音轨，不复制其他轨道、章节或字幕。

三、图片与动图
输入：JPEG、PNG、WebP、BMP、TIFF、ICO、HEIC、HEIF、AVIF、GIF、APNG。
输出：JPEG、PNG、WebP、BMP、TIFF、ICO、HEIC、AVIF、GIF、APNG。
动图输出支持 GIF、WebP、APNG（PNG 也可保存动画）。保持全部帧、帧时序与循环次数；
GIF 的颜色数和时序精度受到格式本身限制。相同画面的连续帧可以等价合并，验证播放内容、总时长及循环信息。
动图导出 JPEG 等静态格式时，明确选择首帧或指定帧；帧序号从 0 开始。
多页 TIFF、HEIF 图片集合不自动丢弃页面，需先拆分。
目标体积 0 表示不限制；有损格式搜索质量，只有勾选“允许自动缩小尺寸”才进一步缩小。
PNG、BMP、TIFF 等无损格式不保证能缩小；无法达标时显示原因。
方向自动校正；透明图转 JPEG/BMP 使用所选背景色，默认白色。
默认清除元数据；可保留 EXIF / ICC。当前以普通 8 位图片转换为主，不承诺 HDR 增益图保留。
动画处理设有像素预算；超限时给出安全尺寸和帧率建议，确认后处理完整内容。

四、iPhone Live Photo
导入 .livp（照片＋MOV 的 ZIP 包），或一次添加原始 HEIC/JPEG 和 MOV。
软件在后台按 ContentIdentifier 配对，文件名相同不代表一定是有效配对。
未自动配对时，在 Live Photo 页面点击“手动配对照片与 MOV”。
一个包必须包含一张照片和一个 MOV；不支持加密包，解包上限 64 项 / 2 GB。
软件检查路径越界、异常压缩比和配对信息。所有解包临时文件位于本项目 temp。

普通格式导出：
“照片＋视频”：在独立子文件夹同时导出，默认 PNG＋原始 MOV。展开高级选项可取消“保持原始视频”，明确选择视频格式和转码参数；两个组件都成功才发布。
可调整照片格式、质量与尺寸，MOV 字节不变；按整组控制体积。
两个文件均验证成功才发布，失败/取消清理整组。这是普通双文件导出，不标记为有效 Live。
静态照片→JPEG / PNG / HEIC / AVIF 等；动态部分→普通视频或 GIF / WebP / APNG。
缺少 Apple 配对元数据但具备可读照片和 MOV 时，仍可导出普通格式。

保留 Live：
照片转换成 JPEG 或 HEIC，可修改质量、尺寸；MOV 字节原样保留，不压缩动态视频。
保留配对 MakerNotes / 标识和 MOV 关键帧轨道；其他元数据是否保留由图片设置控制。
输出为 .livp 或配对文件夹。体积上限针对整组输出；小于原 MOV 大小时不能达标。
输入配对标识不一致或缺少关键帧标记时，拒绝标记为有效 Live。
已用真实 iPhone HEIC/MOV 样例验证配对信息、照片转换和 MOV 字节一致性。
未在真实 iPhone / Apple 照片设备执行重新导入测试；不同应用的 .livp 导入兼容性仍需实机确认。
.livp 不是苹果照片应用的通用导入文件；需要时解包或使用配对文件夹及支持配对的导入方式。

十一、3.3 三模式与信息操作
小白模式和小猫需求卡的“高级选项”可设置体积、尺寸、质量、码率和帧率。
展开可逐文件查看原始与输出摘要；原始码率读不到显示未知，不以预设值冒充。
专业模式另可设置适用编码规格、CPU 10 位 HEVC/VP9/AV1、关键帧间隔与视频元数据保留。
源 HDR/高位深与 8 位输出不一致时预检查提醒；没有自动伪造 HDR 或静默色调映射。

信息模式支持图片、视频、LIVP 及有效配对导入，后台读取常用字段和完整标签。
常用信息点击“编辑”，完整标签选中后编辑；只开放安全的可写描述字段，编码、结构、方向、色彩与 Live 配对标识只读。
“小白更改信息”提供中文直接填写表单，多值字段通过“添加/移除”编辑，无需手写 JSON。
GPS 使用十进制度数；拍摄日期使用 YYYY:MM:DD HH:MM:SS。不同格式可写能力不同，导出会读回核验。

导出原画质副本：无修改时字节复制；修改/清除信息时不重编码。
清除操作保留方向、ICC、Gamma 等显示必要信息，无法安全清除的字段在报告中列出。
ExifTool 不能保证每种格式都完全删除全部信息；不要将报告解释为无条件的隐私消除证明。
Live 清除配对信息后输出普通照片＋视频，不标记为有效 Live。
单文件报告可通过“打开结果 / 清除报告”查看；Live 副本目录附信息处理报告.json。
操作仅影响输出副本，不修改原文件。失败未发布；可调整字段后重试。
需要压缩或换格式时使用信息页“需要压缩 / 换格式…”跳转。

设置支持文字 12–20 pt、间距 6–24 px、导航 110–220 px、详细任务列、结果文件夹前缀。
小猫为 2×–6×整数像素缩放；默认进度提示开启。
离线音效默认轻声 20%，接收/开始/完成/失败播放短提示；悬停无音效，可关闭或试听。
默认完成通知开启、自动打开结果关闭。音效设备不可用不会中断转换。
小猫待机只偶尔眨眼，完成/失败短暂反馈后回到待机；恢复时检测 Windows 置顶属性，不抢焦点。
置顶不覆盖 UAC 安全桌面；减少动画使状态静态显示。
诊断使用 data/diagnostic-settings.json，独立于用户设置，不创建旧程序备份。

补充值不冒充原生值，应用后仅加入待修改；点击导出后才写入副本，并读回核验。
关闭编辑器或切换组件保留草稿；撤销修改只影响当前素材。
没有改动时直接复制；修改时核验图片像素/方向/ICC或音视频压缩包，不能无损写入时失败而不转码。

3.5 便捷修改与放大查看
信息模式标签为“常用信息 / 小白更改信息 / 完整标签”。
小白更改信息可直接填写拍摄时间、设备与镜头、经纬度/海拔、作者、说明及关键词。

未完成或无效的草稿会保留并阻止导出；关键词输入后需点“添加”或按回车，未添加文字不会被静默丢弃。
原生字段优先；补充方式需要明确选择“XMP 补充”或“同名 XMP 附件”，补充值不冒充原生值。
三个标签与编辑面板共享当前素材/组件的修改，切换素材、放大窗口或返回页面不丢草稿。
日期可手动输入 YYYY-MM-DD HH:mm:ss，时区单独填写；原值没有日期时保持为空。

双击常用信息卡片空白处，或点“放大查看”，可在独立窗口查看/编辑全部信息；支持最大化。
关闭放大窗口后回到原标签和滚动位置，重复点击入口激活同一个窗口。
点击“导出修改版”生成原格式、原画质副本，不覆盖原件；修改会重新读回核验，不能无损完成时明确失败。
“打开结果”可查看文件夹及写入报告。Live 按现有组件规则导出，清除配对信息后为普通照片＋视频。
小白使用逐帧明确边界与统一脚底锚点，移除了相邻行混入黑线，五档缩放保持可见脚底位置。

选择“照片＋视频”后，小白模式、专业模式和投喂卡主区域同时显示照片格式、视频格式。
视频格式“原始 MOV · 不转码”保持MOV字节不变；MOV · 转码、MP4、MKV等会按视频参数重新编码。
原始MOV复制时编码、尺寸、帧率与码率只读；选择转码格式后可在高级选项/专业参数中调整。
照片与视频格式独立保留，已保存的旧偏好继续使用。两组件验证成功后整体发布，体积上限按整组计算。
专业详情卡显示原始素材和本次输出；长文字省略并有完整提示，点“查看完整详情”查看全部参数、结果或错误。
窗口小或字号较大时工具栏换行、左区可滚动，右侧只有一个参数滚动区域，底部开始按钮保留。

根目录分类：软件程序、发布包、开发资料、运行数据、文档、output。
开发构建：进入开发资料运行build.ps1；构建临时产物在开发资料\build，最终免安装文件夹在软件程序\MediaForge。
发布ZIP、SHA256与分发说明统一位于发布包。完整报告和迁移清单位于文档。
原有output不移动；用户指定的其他保存目录不批量改写。原媒体不修改。
整个MediaForge文件夹搬到项目以外可独立离线运行，配置、日志、临时和默认输出保存到该文件夹内。
若搬走后也要使用完整项目的个人偏好，可自行将运行数据\data中的settings.json复制到新软件目录的data中；外部输出路径仍需可写。
旧根目录.pytest_cache因原Windows权限禁止读取/移动而保留；不更改其权限，新构建禁用此旧缓存。

3.8 小白陪伴、游乐场与声音
小白新增洗脸、舔爪、挠耳、嗅闻、抖耳、打哈欠、趴下、抱尾等待机动作；
以及蹭手、吃零食、开心小跳、害羞、扑抓和接球，保留已有摇尾/伸懒腰/打盹。
设置→小白：安静20–40秒、标准10–25秒、活泼5–15秒，随机调度避免连续重复；默认标准。
单击摸头；短暂停留可抬头/追视/抖耳；双击打开主界面；按住拖动位置。
右键“和小白互动”可主动喂零食、蹭蹭、叫一声或休息。设置中可预览动作。
右键“小白游乐场”打开逗猫棒或抛接小球，同一时间只有一个面板。
逗猫棒：开始后移动玩具进入虚线圈再点击计分，也可按空格/回车互动。
抛接小球：每轮30秒，点击抛球，看到“现在接球”再点一次；太早或太晚算未接住。
暂停会停止计时，重玩清零本轮成绩；结束/关闭面板停止游戏计时器和声音。
玩具仅在面板内显示，小白不在桌面上漫步；面板跟随小白位置与屏幕可见区域。
收到文件、读取素材、待确认投喂和转换会停止游戏。完成后需要用户主动重新开启。
处理期间互动不覆盖工作表情或真实进度。隐藏小白停止装饰动画；减少动画用静态表情/玩具与文字反馈。

设置→声音集中控制：总开关、总音量、转换提示/宠物互动/游戏音效各自开关和相对音量、轻喵/呼噜及待机发声。
原音量偏好继续生效，新配置总音量20%、分类100%、自动待机发声关闭。
分类实际音量=总音量×分类音量。设为0或关闭开关会立即停止相应声音。
接收/开始/完成/失败每次事件播放一次；同类声音不叠加，完成/失败提示优先。
猫叫和呼噜至少间隔8秒；允许待机发声后也至少间隔60秒。鼠标悬停不发声。
试听尊重总开关、分类静音和猫叫开关；无音频设备不妨碍媒体转换。
新增声音为离线程序合成短音，拟声猫叫并非真实猫录音。
五页设置按页恢复默认，声音页不会重置媒体参数、输出目录或宠物位置。
